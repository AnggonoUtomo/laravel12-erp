# Login Activity

**Module:** `Console.LoginActivities`
**Architecture:** DDD-lite

## Ownership

Riwayat autentikasi: login berhasil/gagal, logout, konteks perangkat, browser, platform, dan metadata request.

## Public Contract

Route `login-activities.index`, halaman Inertia `console/login-activities/index`, permission `login-activities.view`, dan pencatatan aktivitas autentikasi dipertahankan.
