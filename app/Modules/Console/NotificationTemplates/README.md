# Notification Templates

**Module:** `Console.NotificationTemplates`
**Architecture:** DDD-lite

## Ownership

Template notifikasi aplikasi, variable render, status aktif, dan perubahan template yang tercatat pada audit trail.

## Public Contract

Route `notification-templates.*`, halaman Inertia `console/notification-templates/index`, permission `notification-templates.*`, dan render template untuk notifikasi internal dipertahankan.
