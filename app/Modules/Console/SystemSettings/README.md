# System Settings

**Module:** `Console.SystemSettings`
**Architecture:** DDD-lite

## Ownership

Konfigurasi aplikasi dinamis: email, branding, localization, pagination, security policy, maintenance mode, dan health.

## Public Contract

Route `system-settings.*`, halaman Inertia `console/system-settings/index`, serta `SystemSettingService` tetap menjadi contract yang digunakan consumer internal.
